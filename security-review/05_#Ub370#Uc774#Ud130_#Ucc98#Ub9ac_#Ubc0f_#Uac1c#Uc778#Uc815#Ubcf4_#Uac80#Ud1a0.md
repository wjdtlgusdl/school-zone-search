# 데이터 처리 및 개인정보 검토

## 1. 개인정보 처리 여부

현재 웹앱은 이용자의 개인정보를 수집, 저장, 처리하지 않는다.

| 항목 | 처리 여부 | 비고 |
| --- | --- | --- |
| 이름 | 아니오 | 입력받지 않음 |
| 생년월일 | 아니오 | 입력받지 않음 |
| 전화번호 | 아니오 | 입력받지 않음 |
| 이메일 | 아니오 | 입력받지 않음 |
| 주민등록번호 등 고유식별정보 | 아니오 | 입력받지 않음 |
| 민감정보 | 아니오 | 입력받지 않음 |
| 회원 계정 | 아니오 | 회원 기능 없음 |
| 위치정보 자동 수집 | 아니오 | geolocation 권한 차단 |
| 주소 입력값 저장 | 아니오 | 브라우저 내 검색에만 사용 |

## 2. 이용자 입력값 처리

이용자가 입력하는 값은 다음과 같다.

- 주소
- 아파트명
- 개발지구명
- 학교명

처리 방식:

1. 브라우저에서 입력값을 받는다.
2. 같은 사이트에서 제공하는 정적 JSON 데이터를 불러온다.
3. JavaScript가 브라우저 내부에서 검색한다.
4. 결과를 화면에 표시한다.
5. 입력값을 서버, DB, 외부 API로 전송하지 않는다.

## 3. 브라우저 저장소 사용

| 저장소 | 사용 여부 | 내용 |
| --- | --- | --- |
| Cookie | 사용 안 함 | 없음 |
| localStorage | 사용 | 다크모드/라이트모드 설정값 |
| sessionStorage | 사용 안 함 | 없음 |
| IndexedDB | 사용 안 함 | 없음 |

`localStorage`에는 주소, 학교명, 검색 기록을 저장하지 않는다.

## 4. 배포 데이터

| 파일 | 내용 | 개인정보 포함 여부 |
| --- | --- | --- |
| `public/data/core.json` | 통리반 및 통학구역 검색 데이터 | 포함하지 않음으로 관리 |
| `public/data/roads.json` | 도로명주소/지번주소/건물명 검색 데이터 | 공개 가능 자료 기준 확인 필요 |
| `public/data/suggestions.json` | 자동완성 추천어 | 포함하지 않음으로 관리 |

## 5. 데이터 공개 가능성 확인

배포 전 다음 항목을 확인한다.

- 원본 자료가 공개 가능한 자료인지 확인
- 개인정보 또는 비공개 정보가 포함되지 않았는지 확인
- 내부망 정보, 계정정보, IP 현황, 시스템 구성정보가 포함되지 않았는지 확인
- 데이터 기준일과 출처를 관리 문서에 기록
- 자료 관리 시점과 서비스 시점 차이로 실제와 다를 수 있다는 안내 문구 제공

현재 웹앱 화면에는 다음 안내를 표시한다.

> 자료 관리 시점과 서비스 시점의 차이로 인해 실제와 차이가 발생할 수 있으므로 참조하시기 바라며, 정확한 사항은 관련부서(학생배치과)에 확인하시기 바랍니다.

## 6. 개인정보 노출 점검 절차

데이터 갱신 전후 다음을 점검한다.

```bash
npm run build:data
npm run smoke
npm run audit:security
```

추가 수동 점검:

- `public/data/*.json`에 전화번호, 이메일, 주민등록번호 형식 데이터가 포함되어 있는지 확인
- 담당자 이름, 내부 연락처, 계정정보, 토큰이 포함되어 있는지 확인
- 원본 파일이 GitHub에 커밋되지 않았는지 확인

권고 검색어:

```bash
rg -n "주민|전화|휴대|010-|@|password|token|secret|apikey|api_key" public/data
```

## 7. 보존 및 파기

- 서비스는 이용자 검색 기록을 보존하지 않는다.
- 원본 자료는 담당 부서 보관 정책에 따른다.
- 오래된 원본 자료는 기관 문서보존 및 개인정보보호 기준에 따라 파기 또는 별도 보관한다.
- 공개 배포 JSON은 최신 자료 생성 시 교체한다.

## 8. 잔여 위험

- 공개 JSON 데이터에 잘못된 자료가 포함되면 이용자에게 잘못된 통학구역 정보가 표시될 수 있다.
- Cloudflare 접속 로그 등 플랫폼 로그는 Cloudflare 설정 및 기관 운영 정책에 따라 별도 검토가 필요하다.
- 도로명주소 및 건물명 데이터의 공개 가능성은 원본 자료 출처와 이용 조건을 확인해야 한다.
